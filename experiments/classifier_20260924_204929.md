# Run: classifier_20260924_204929 — CPU smoke test (pipeline proof)

**What changed / why:** First end-to-end execution of the classifier training
path on `classifier_dataset_v1` (32-example subset, 1 epoch, CPU). Purpose:
prove the pipeline, not produce a model. All three failures encountered on
the way were fixed — this is the record.

**Dataset:** classifier_dataset_v1 (hashes in the manifest).
**Hardware:** CPU only (torch 2.14.0+cpu, transformers 5.17.0).
**Elapsed:** ~4 minutes total; 8 train steps at ~18 s/step, eval 38 s.
**Result:** pipeline completed; artifact saved to `models/classifier/smoke`
(git-ignored, weights never in git); manifest written with split hashes.
Eval loss 3.89 is meaningless at this scale — the smoke run validates
mechanics only.

**What failed (and the fixes, all regression-relevant):**

1. `KeyError: 'seed'` — TrainingArguments read config["seed"] directly;
   config had no seed key. Fix: `config.get("seed", 42)` with Experiment
   seeding unchanged.
2. `TypeError: unexpected keyword 'warmup_ratio'` — transformers 5 dropped
   `warmup_ratio`; the ratio is now computed into `warmup_steps` from
   dataset size, batch size, and epochs.
3. `RepresenterError: cannot represent '2.14.0+cpu'` — `torch.__version__`
   is a TorchVersion object, not a str; PyYAML refused it in the manifest.
   Fix: `str()` coercion in `detect_hardware`.

Also fixed along the way: PROJECT_ROOT off-by-one in
`training/common/experiment.py` (was resolving above the repo; now covered
by tests/test_paths.py), and dataset directory naming aligned to the brief
(`datasets/classifier/`, not `datasets/classify/`).
